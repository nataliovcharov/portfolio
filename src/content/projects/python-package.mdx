## Overview

We built and published a Python package with four functions whose behaviour adapts to
user-defined arguments.

## How it's built

- **pipenv** for dependency and environment management.
- **pytest** test suite, run automatically on every push with **GitHub Actions**.
- Published to **PyPI**, so anyone can install it with `pip`.

## How we worked

A structured team workflow: feature branches, pull requests with peer review, and clear
documentation so others could use and contribute to the package.
